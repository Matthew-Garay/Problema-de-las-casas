# Guia de Instalacion - Problema de las Casas

Esta guia te ayuda a ejecutar el proyecto en tu entorno local.

## Requisitos previos

- SWI-Prolog 8.x

## Instalacion

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Matthew-Garay/Problema-de-las-casas.git
   cd Problema-de-las-casas
   ```
2. Ejecuta el programa:
   ```bash
   swipl -s problemascasas3.pl -g "main" -t "halt"
   ```

## Verificacion

El programa debe mostrar en consola la solucion completa del acertijo de las cinco casas, indicando la asignacion de color, nacionalidad, mascota, bebida y cigarro para cada casa.
